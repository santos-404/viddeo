# Viddeo editor demo session

This is a tiny synthetic recording for trying the editor without starting a capture. It contains an 8-second 720p test-pattern video, sample pointer events, and a project timeline with a trim and two speed changes. It has no audio or camera track.

1. Open Viddeo.
2. Choose **Load Session…** and select `session.json` in this folder.
3. The app reads `raw.mp4` and `project.json` from the same folder and opens the editor.

The project is a normal Viddeo session folder; edits and exports are saved alongside these files.
